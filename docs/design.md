# 清读 Qingdu：离线优先的浏览器朗读插件

2026-10-28 · 已于本日经用户确认的产品方案

## 用户目标

基于 REA 对 Read Aloud 发布物的分析，独立实现一个适用于 Windows 与 macOS 的 Chrome / Edge 插件。核心朗读功能无需梯子，安装好本地语音后可以断网使用。项目创建在 armin926 GitHub 账号下，建议仓库名 qingdu，默认私有。

## 三条实现路线

1. **本地语音优先（推荐）**：使用浏览器 chrome.tts 接入操作系统语音，仅允许本地系统声音。没有云服务账号、代理或运行时模型下载。优点是安装包小、离线稳定、文章留在设备上；音质取决于已安装的系统语音。
2. **国内云语音优先**：接入国内官方 TTS。声音选择多，但需要账号、密钥、费用和网络，无法保证离线。适合作为后续可选增强。
3. **内置神经网络语音模型**：使用本地模型在浏览器合成。可独立提供声音，但模型体积、启动速度和硬件要求明显增加，需要单独评估授权与跨平台性能。

本次推荐路线 1，先交付完整、可安装的产品。后续国内云语音和本地高质量模型，以实际评测决定是否加入。

## 首版产品范围

- 中文侧栏播放器：朗读网页正文、选中文字或粘贴文本；可导入 TXT / Markdown。
- 自动提取正文，过滤导航和隐藏内容；提供提取预览，提取失败时可使用选择文本或粘贴入口。
- 本地语音检测与选择；中文声音缺失时提示 Windows / macOS 安装路径；远程声音不会自动启用。
- 播放、暂停、继续、停止、前后句、点击句子跳读；语速和音量调整。
- 侧栏句子高亮、自动跟随；网页能准确映射时高亮相应正文，不为了高亮改写网页结构。
- 文章收藏与阅读进度；每句保存位置，重启浏览器后可继续。文章及设置保存在本地。
- 字面发音替换词典、跳过代码块开关、睡眠定时器和常用快捷键。
- 清晰错误提示、键盘可操作控件、明暗主题；权限仅用于用户触发的当前网页读取、本地存储和朗读。

首版不承诺 PDF、图片 OCR、跨设备同步或下载合成音频；这些能力需要不同的解析或合成路径，列入有验收标准的后续路线图。

## 实现与数据流

使用 Manifest V3。用户触发读取当前页 → 内容提取与句子切分 → 侧栏预览 → 后台本地 TTS 逐句朗读 → 更新高亮与本地进度。后台控制器统一处理暂停、跳句、停止及过期事件，避免快速操作造成重复播放。浏览器休眠或异常关闭时保留位置，恢复后等待用户继续。

新项目独立编写实现；原发布物只作为研究证据，不复制它的代码、素材或品牌。运行时不加载远程脚本，不上传文章，不保留云 API 密钥。

## 验收

- 安装包可以作为解压扩展加载；必需文件和 Manifest 权限一致。
- 本地声音可用时，断网仍能读取已打开的文章并朗读；插件无 Google 请求和默认远程声音。
- 测试中文、英文、长段落、连续快速播放/暂停/跳读、进度恢复、词典替换及定时停止。
- 浏览器检查侧栏布局、键盘交互、正文提取和本地数据恢复；验证真正的扩展环境，若宿主无法提供某项实际测试，准确记录限制。
- 提供源码、安装说明、隐私说明、REA 调查报告、测试结果与扩展 ZIP。
- 当前宿主为 macOS，Windows 的实际语音质量及安装后行为需要 Windows 环境验收；不将模拟 API 测试称为 Windows 实测。

## 0.1.1 用户反馈后的修订

用户报告侧栏读取普通网页失败，并明确要求选中文字后出现浮动入口。真实 Chrome 156 复现显示原版缺少网站授权；仅 activeTab 无法覆盖侧栏读取当前网站的场景。0.1.1 请求 HTTP/HTTPS 网站权限，并在网页注入选中文字按钮。点击按钮导入选中的段落、打开侧栏并等待播放；不自动朗读，不发送远程请求。用户可以按网站限制扩展访问。
