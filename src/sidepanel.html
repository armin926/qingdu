安装中文声音

Windows 10 / 11
设置 → 时间和语言 → 语言和区域 → 添加中文（简体，中国）→ 语言选项 → 下载「语音」。重新启动浏览器后刷新。部分 OneCore / 自然声音不会暴露给 Chrome 的 SAPI 5，请以此处列出的本地声音为准。

macOS
系统设置 → 辅助功能 → 朗读内容（或「朗读与语音」）→ 系统声音 → 管理声音 → 中文 → 下载声音。下载完成后重启浏览器并刷新。

声音只需安装一次，之后可离线使用。清读只列出操作系统提供的本地声音，音质和语言范围取决于系统。
