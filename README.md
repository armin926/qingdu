# 清读 Qingdu

面向 Windows / macOS 的 Chrome / Edge 浏览器朗读插件。默认使用本地系统语音，运行时没有远程语音、语言识别、字体或统计请求；安装好系统声音后，核心朗读可离线运行。

> 0.1.1 修复侧栏读取缺少网站权限的问题，并新增选中文字后的浮动清读按钮。已在真实 macOS Chrome 156 验证读取、选中导入、本地保存和短文离线朗读。Windows 实机与长时间后台播放仍需验收。

## 安装

1. 下载仓库中的 `qingdu-0.1.1.zip`，解压到固定目录。也可以直接下载仓库 ZIP，解压后使用项目根目录。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择含有 `manifest.json` 的目录。
4. 固定清读图标。在普通网页点击图标打开侧栏，点击「读取当前页 / 选中文字」。确认提取预览后播放。
5. 如果显示缺少中文声音，去设置查看安装指引。安装完成后重启浏览器并刷新声音列表。

需要 Chrome / Edge 120+。此版本通过解压方式安装，不依赖 Chrome 商店下载。不要删除加载目录，否则浏览器无法再次载入。

## 从 0.1.0 更新

用新安装包覆盖原来的解压目录，在扩展管理页点击清读的「重新加载」，确认网站访问权限，然后刷新已打开的网页。保持原目录可以保留扩展 ID 与本地书架。若另选新目录安装，浏览器会视为另一份扩展。

## 功能

- 选中文字后显示浮动「清读」按钮；点击即导入并打开侧栏，等待你按播放。
- 读取网页正文、选中文字、粘贴文本以及 UTF-8 TXT / Markdown 文件。
- 中文侧栏、逐句播放、暂停/继续、前后句、点击句子跳读、语速与音量。
- 侧栏句子高亮；当前网页有映射时高亮对应段落。收藏过的文章再次打开时保留进度，重新读取网页后恢复页面映射。
- 本地书架与每篇文章的位置；默认保留最近 12 篇、总计 40 万字，单篇最多 80,000 字。容量满后最旧文章会移除，收藏标记不锁定容量。
- 字面发音替换（例如 `API=诶批艾`）、代码块过滤、睡眠定时、明暗主题。
- `Alt+Shift+R` 读取当前页，`Alt+Shift+P` 播放/暂停。可在浏览器的扩展快捷键页修改；macOS 键名对应 Option。

网页内容脚本用于检测选中状态和显示清读按钮；只有你点击读取、浮动按钮或右键菜单时才保存文章。插件请求 HTTP/HTTPS 网站访问权限，你可以在浏览器扩展管理里按网站限制；未允许的网站不会自动显示按钮。浏览器内部页面、商店、受限页面及 PDF 浏览器页面通常不允许注入，请使用复制/粘贴文本。正文提取采用通用可见 DOM 策略；封闭 Shadow DOM、复杂 iframe、图片和 Canvas 内容尚不支持。

关闭侧栏后朗读由后台继续；暂停、停止和异常关闭保留当前句子，浏览器重新启动后等待你点击继续。浏览器休眠或回收后台时可能重读当前句，长时间后台播放需进一步真实扩展环境验收。

## 本地中文声音

**Windows**：设置 → 时间和语言 → 语言和区域 → 中文（简体，中国）→ 语言选项 → 下载「语音」。Chrome 使用 Windows SAPI 5，某些 OneCore / 自然声音不会出现在它的列表中；以插件实际枚举出的声音为准。

**macOS**：系统设置 → 辅助功能 → 朗读内容（或「朗读与语音」）→ 系统声音 → 管理声音 → 中文。下载完成后重启浏览器。声音首次安装需要网络，以后的合成在本地。

自动选声只允许系统原生声音，并过滤 `remote: true` 及其他扩展注册的引擎。没有目标语言声音时会明确报错，不自动改用远程声音。手动选择允许按用户意愿用其他语言的本地声音。

## 开发与检查

无 npm 依赖，无需 `npm install`。

```sh
npm test
npm run check
npm run pack
```

Node.js 20+。打包脚本需要系统 `zip` 命令；Windows 可手动压缩根目录的 `manifest.json`、`src/`、`icons/`、`README.md`、`PRIVACY.md` 和 `LICENSE`。输出在 `dist/qingdu/` 与 `dist/qingdu-0.1.1.zip`。

- [验证记录](docs/validation.md) 区分模拟 API、真实 DOM、操作系统语音和未验证的行为。
- [Read Aloud REA 调查](docs/read-aloud-rea.md) 记录发布物身份、证据 ID、网络路径和研究限制。
- [后续优化路线](docs/roadmap.md) 列出自然声音、PDF、网站适配的验收要求。
- [隐私说明](PRIVACY.md)
